# Project media

Each project folder keeps **one file per use** — no duplicate screenshots.

## Naming

| Pattern | Use |
|--------|-----|
| `wwim-*.png` / `wwim-*.mp4` / `wwim-*.mov` | Weather Where It Matters — referenced from `projects.html` |
| `urbanlens-*` | Urban Lens — same |

macOS screenshots like `Screenshot 2026-…` were copies of these; they were removed to avoid clutter. If you replace an asset, **overwrite the `wwim-*` / `urbanlens-*` file** (or update the path in `projects.html`).
